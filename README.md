# 📻 GoldenEra Songs — Vintage Radio Melodies

An atmospheric, nostalgic web radio experience playing timeless Golden Era Hindi classics against a warm vintage aesthetic with ambient analog crackles and a real-time retro timepiece.

---

## ✨ Features

- **🎶 Handpicked Golden Era Melodies**: Classic melodies categorized by moods (Romantic, Nostalgic, Melancholy, Evergreen).
- **📻 Responsive Vintage Aesthetic**: Features a beautiful vintage radio background image designed to fit seamlessly on mobile phones, tablets, and desktop displays.
- **🕰️ Real-Time Vintage Clock**: An attractive glowing amber retro clock with pulsing tube indicators, live seconds, AM/PM, and date display.
- **🔊 Ambient Sound Engine**: Optional warm fireplace crackle and vinyl record textures layered beneath music.
- **🎛️ Full Playback Controls**:
  - Play / Pause, Next & Previous track
  - Random Shuffle mode with persistent state
  - Smooth interactive seeker bar
  - Volume slider and one-click mute toggle
- **📜 Melodies Archive Drawer**: Quick search by song title, Hindi title, artist, or movie, with category filters.
- **⌨️ Keyboard Shortcuts**:
  - <kbd>Space</kbd>: Play / Pause
  - <kbd>→</kbd> / <kbd>←</kbd>: Next / Previous Track
  - <kbd>S</kbd>: Toggle Random Shuffle
  - <kbd>L</kbd>: Open / Close Melodies Archive

---

## 🛠️ Tech Stack

- **Framework**: React 19, TypeScript
- **Bundler & Tooling**: Vite
- **Styling**: TailwindCSS & Custom Analog Vintage Tokens
- **Icons**: Lucide React
- **Audio Engine**: Web Audio API & HTML5 Audio

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or yarn / bun

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/SaquibNazeer01/GoldenEra-Songs.git
   cd GoldenEra-Songs
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run the development server:**
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) in your browser.

4. **Build for production:**
   ```bash
   npm run build
   ```
